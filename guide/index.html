What you need

Three things on hand before you start.

Python 3

Runs the bot script on your computer.

ADB installed

Android Debug Bridge lets your computer send taps to the phone.

Android phone + data cable

A charging-only cable won't work. Use one that supports data transfer.

Setup in six steps

Do these once. After that, running the bot is one command.

  1. Clone the repo

    Download the project to your computer.

    git clone https://github.com/hassancodes/snapscore.git

  2. Install the requirements

    Move into the folder and install the Python packages.

    cd snapscore && pip install -r requirements.txt

  3. Turn on USB debugging

    On your phone, open Settings → About phone and tap Build number seven times to unlock Developer options. Then switch on USB debugging.

  4. Connect the phone

    Plug it in, accept the debugging prompt on the screen, then check that ADB sees it.

    adb devices

    Your device should show up in the list as device

  5. Find your tap coordinates

    The bot needs the screen position of each button it taps. In Developer options, turn on Show taps or Pointer location, open Snapchat, and note where the camera button, send button and friends sit.

  6. Add them to the script

    Open snapscore.py and replace the coordinates with the ones from your phone. Every screen size is different, so this step makes the bot work on your device.

Run the bot

Open Snapchat on the camera screen, then start the script.

One snap at a time

The default mode. Sends to one person per round.

python snapscore.py

Many people at once

Add the exp flag to send to a group of friends together. Sending to 5 people at the same time is about 5× faster.

python snapscore.py exp

Use at your own risk. Automating Snapchat may go against its terms of service and can get an account limited or locked. Try it on an account you can afford to lose.

What can be improved

Ideas for making the bot smarter. Pull requests welcome.

Find buttons by image

Take a screenshot of the phone, match it against a small image of the button, and read the coordinates from the match instead of typing them in.

Tap automatically

Use those detected coordinates to perform the taps, so the bot works on any screen size with no setup.
